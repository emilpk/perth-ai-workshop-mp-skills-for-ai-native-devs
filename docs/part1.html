Part 1

Triage, then find out why

Bug reports are piling up on the shop. Before anyone fixes anything, work out which reports are real, which bugs matter, and what actually causes them.

On Codex, type $ instead of /, for example $triage. In an agent without commands, ask for the skill by name.

  1. Read the bug reports

    They're GitHub issues written by "customers": some vague, some wrong, some real.

    Open the bug reports

    We’ll show you which copy of the shop to work in.

  2. Triage one

    /triage issue #1

    Swap in the number of the issue you picked.

    What does this do?
    What is triage?
    Deciding what a report needs next, before anyone writes code. The agent reads the report and the code, asks you questions, and moves the issue to one of five states.
    The five states
    needs-triage not looked at yet · needs-info waiting on the reporter · ready-for-agent clear enough for an agent to build · ready-for-human needs a person's judgement · wontfix not a bug, or not worth it.
    Why bother?
    An agent will happily "fix" a bug that isn't one. Triage is where you catch that, cheaply.

  3. Find the cause, not the symptom

    Use the diagnosing-bugs skill on issue #1. Show me a command that fails because of this bug before you change any code.
    What does this do?
    Why a failing command first?
    If you can make the bug happen on demand, you can prove it's gone. Without that, "fixed" is a guess.
    What happens next?
    The agent narrows the bug down, tests its theories one at a time, then fixes it and keeps the failing check as a regression test.
    Do I always need this?
    No. For an obvious bug, skip to the fix. Save this for the ones that resist a first look.

  4. Fix it, test first

    /implement issue #1

    The agent writes a test that fails, makes it pass, then reviews its own change.

  5. Ask why it got in

    /retro

    Run it in the same session, before you clear. It suggests changes to the repo's setup, like a check or a written rule, that would have stopped this bug arriving.
