  1. Install the skills

    claude plugin install mattpocock-skills@claude-plugins-official
    codex plugin marketplace add mattpocock/skills

    npx skills@latest add mattpocock/skills

    Works for Cursor, Windsurf, OpenCode, Amp and more. It asks which agent and which skills: take them all, and make sure setup-matt-pocock-skills is ticked.

gemini skills install https://github.com/mattpocock/skills.git --path skills/productivity

    Into your agent's own settings folder, not into a repo, so it works in every project.

  2. Make your own copy of the shop

    Create my copy on GitHub

    Tick Include all branches, or Part 2 won't come with it. Then clone it and switch to Part 2. Swap in your GitHub name and the name you gave the repo.

    gh repo clone YOUR-NAME/YOUR-REPO
cd YOUR-REPO
git switch mash/part-2-new-features

    No gh? Use git clone https://github.com/YOUR-NAME/YOUR-REPO. Already made a copy in Part 1? Switch to Part 2.

    What does this do?
    What is this repo?
    A small online shop: a Python (FastAPI) backend with a SQLite database, and a React frontend. main is the buggy shop from Part 1. mash/part-2-new-features has every bug fixed and 38 tests passing.
    Why a copy?
    The button makes a brand new repo in your account. Its issues and pull requests are yours, so your agent can file tickets and open PRs without touching anyone else's work.
    Public or private?
    Either works.

  3. Set up the skills in your copy

    Start your agent in the repo folder, then run the setup skill.

    claude
/setup-matt-pocock-skills
    codex
$setup-matt-pocock-skills
    copilot
/setup-matt-pocock-skills
    /setup-matt-pocock-skills

    If your agent has no slash commands, type: Use the setup-matt-pocock-skills skill.

    When it asks where issues go, pick GitHub if gh is signed in. Otherwise pick local files. Say yes to the default labels.

    What does this do?
    What will it ask?
    Up to three things, one at a time, each with a recommended answer: where issues live (GitHub, GitLab or local files), whether to keep the default triage labels, and where the glossary and decision records go.
    What does it change?
    It shows you a draft first, then adds an "Agent skills" section to the repo's instructions file and writes a few short notes under docs/agents/. Commit them like any other change.
    Why do I need it?
    The skills that write specs and tickets need to know where to put them. You run it once per repo.
    Why the $?
    In Codex, $name runs a skill by name. Skills you start yourself, like this one, only run that way.
    Local files?
    Tickets go in a .scratch/ folder as Markdown instead of GitHub Issues. Everything else works the same.

  4. Run the shop

    Needs uv and Node. Missing one? See below.

    Terminal 1
    cd python-eshop/backend
uv sync
uv run python run.py
    Terminal 2
    cd python-eshop/frontend
npm install
npm run dev

    Open 127.0.0.1:4321. Sign in with demouser@perthai.com.au and Pass@word1.

    What does this do?
    Terminal 1
    uv sync downloads the right Python and the backend's packages into a local .venv folder. run.py starts the API on port 8765 and creates and fills eshop.db the first time.
    Terminal 2
    npm install downloads the frontend's packages, which takes a minute. npm run dev serves the shop on port 4321 and passes API calls through to Terminal 1.
    Why two terminals?
    Both keep running until you press Ctrl+C. Leave them open and use a third terminal for your agent.
    Want the tests?
    In python-eshop/backend, run uv run pytest. Your agent runs them too when it builds with the tdd skill.
    Port already in use?
    Something else is on 8765 or 4321, often a copy of the shop from the first half. Stop it with Ctrl+C in its terminal.

In PowerShell, then close and reopen it.

winget install Git.Git OpenJS.NodeJS.LTS GitHub.cli
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

In Terminal, with Homebrew.

xcode-select --install
brew install node gh uv

Use your distro's package manager for git, gh and Node 18+.

sudo apt install git gh nodejs npm
curl -LsSf https://astral.sh/uv/install.sh | sh

You don't need Python. uv fetches the right version. Sign in to GitHub with gh auth login.
